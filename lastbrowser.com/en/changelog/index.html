v0.1.52 · Latest Release Current
October 10, 2026

Release 0.1.52 consolidates hotfixes for tab pinning, profile menu interactions, Chromium session identity preservation during OAuth, and Windows long-path hardware scans.

  • Tab Pinning & Profile Menu: Reliable drag-and-drop for pinned tabs and responsive pointer interaction across compact and split viewports.
  • Chromium Identity & OAuth: Full preservation of Chromium user identity during Google and third-party OAuth flows without session resets.
  • Smart Track Spaces: Resilient Space setup and error-free hardware scanning across deep Windows directory trees and long paths.
  • Model Resolution & Stability: Guaranteed safe default model resolution for new profiles, hardened worker lifecycle, and Authenticode + Widevine VMP signing.
v0.1.47 · TEST prereleaseOctober 7, 2026

These items describe focused source corrections in this separate test version. The signed test package is available; practical runtime and provider acceptance remain open. Test release on GitHub.

  • Providers and model catalog: Requests are bound to the saved Space/profile context and payloads receive strict validation. Additional bridge diagnostics help locate early chat-start failures; they do not confirm the cause of the earlier guest timeout.
  • Quick Chat: Transcript and status remain associated with their original context after a Space switch. Reset is complete only after a positive acknowledgment; stale or unavailable model selections are blocked.
  • MiMo settings: Provider-specific labeling and confirmation-based key status prevent an unverified state from appearing as a saved connection. Successful inference has not been demonstrated.
  • Other UI changes: Update notice and “Update now”, post-update notice, log alias, and hiding the ineffective Trust switch are included in the test package; visible runtime behavior has not been accepted.

This is a test prerelease, not a stable version. The v0.1.52 stable-download and update targets remain unchanged. VM, provider, and two-profile acceptance remain open; not Store-certified.

v0.1.45 · publishedOctober 5, 2026

Version 0.1.45 was released on October 5, 2026. It brings the compact composer with AUTO and “More”, compact goal controls, a closer link between Space Assistant and Quick Chat, and a simpler local setup flow.

  • AUTO: An eligible configured orchestrator is preferred. Otherwise, AUTO uses fresh observed limit headroom only when known for every candidate, then compares active/recent local requests and uses configured order to break ties. It does not optimize semantic quality or cost. The 350M router failed its independent quality holdout; Teamwork remains a separate explicit choice.
  • Local AI: PC checks and setup guidance exist in source; production inference, runtime/license evidence, and package acceptance remain open. The RAM guard has not been qualified across supported hardware.
  • Teamwork: The three-step loopback test passed on a controlled local path. It does not establish paid-model or external-provider quality.
  • Signed setup and portable downloads, with their checksums, are available on the download page.

v0.1.33
September 25, 2026

Feature & Stability Update: Teamwork and Smart Track configuration, Zen Hover Reveal, Space Setup Assistant, and Dock Fisheye Animation.

  • Teamwork & Smart Track Orchestrator: Multi-model collaborative agent team (Lead, Researcher, Analyst, Critic) and single-lane token-efficient Smart Track mode with adaptive effort tiers (Low, Medium, High).
  • Focus Mode Hover Reveal: 8px left edge hover zone smoothly slides the sidebar into view as a floating overlay without displacing web page layout.
  • Dock Fisheye & Hover Titles: Fluid macOS-inspired dock fisheye effect with dynamic scaling and progressive dimming of adjacent icons in slim dock mode.
  • Space Setup Assistant: 3-step creation wizard for new spaces with presets (Coding, Research, Media, Blank), accent colors, and custom AI model routing.
  • Downloads Overlay & Floating Dock: Detachable downloads panel with persistent screen positioning, pill minimization, and multiple docking slots.
  • Instant Live Auto-Save: Theme, font size, page zoom, and notification preferences now persist instantly with zero delay without a separate save button.
