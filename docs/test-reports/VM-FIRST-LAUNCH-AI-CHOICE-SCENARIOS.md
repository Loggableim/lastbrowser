## Scope and guardrails

- Observe only the first-run AI choice and browser setup flow, persistence across restart, and later settings access. Do not test provider quality, run inference, sign in, add credentials, or broaden provider budgets.
- In every `No AI` scenario, assert there is no inference/provider turn, model-weight load or download, local-AI bootstrap/download, or credential mutation triggered by choosing No, completing browser-only setup, restarting, or opening settings. Harmless read-only status/catalog requests are allowed; record them as such and do not misclassify them as inference. Do not click provider-connect, model-probe, submit, or download controls.
- Use only a newly provisioned synthetic Guest profile or an explicitly prepared disposable synthetic profile. Never reset/overwrite a user's existing profile. For legacy-credential preservation use a synthetic legacy fixture/profile supplied for this exact candidate; do not inspect, copy, expose, or alter real credentials.
- Keep import and default-browser choices optional. Do not import real browser data or change the Guest OS default-browser association. Use a supplied synthetic bookmark fixture if exercising import; otherwise record it `NOT_TESTED`.
- Save-failure testing is conditional: use only a pre-existing, explicitly authorized Guest-only failure mechanism. Do not edit product files, inject faults from the host, mutate profile files, or turn on debug overrides to manufacture a failure. Without such a mechanism record `NOT_TESTED`.
- No source build/repair, install/uninstall of the candidate, runner activation, host/harness UI substitution, provider/account setup, network/account change, or package publication is authorized by this plan.
