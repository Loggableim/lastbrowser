ナレッジベース & 技術サポート

どのようなサポートが 必要ですか？

インストール、セキュリティ、AI設定に関するよくある質問をご確認いただくか、サポート窓口まで直接お問い合わせください。

Windowsへのインストール方法は？

ダウンロードページからインストーラーを入手して実行するだけです。レジストリを変更せず管理者権限も不要なポータブル版（Portable .exe）もご用意しています。

Windows SmartScreenの警告が出るのはなぜ？

リリース直後のオープンソースソフトであるため、Microsoftのサーバー上で十分な実績評価が蓄積されるまでの正常な挙動です。「詳細情報」をクリックし、「実行」を選択してください。

閲覧履歴が外部サーバーに送信されることはありますか？

一切ありません。LastbrowserはLocal-First（ローカルファースト）原則を徹底しています。不本意なテレメトリはなく、すべて%APPDATA%\Lastbrowser内にWindows DPAPIで暗号化保存されます。

独自のAIキー（BYOK）の設定方法は？

Sidekickの設定を開き、利用可能なAIプロバイダーの接続手順に従ってください。Ollamaも設定できます。利用条件や料金は各サービスによって異なります。

Chrome Web Storeの拡張機能は使えますか？

はい。LastbrowserはChromium Manifest V3（MV3）拡張機能をネイティブで完全にサポートしています。Chrome Web Storeから直接追加可能です。

商用ライセンスや法人導入の問い合わせ先は？

企業利用ライセンス、フリート展開、サポートSLA契約については、公式窓口：rainer@dominik.inまでお気軽にお問い合わせください。
