Lokales Dateisystem & Konfiguration

Lastbrowser speichert alle Anwendungsdaten lokal auf Ihrem PC. Es findet keinerlei unaufgeforderte Datenübertragung an Cloud-Dienste statt.

Speicherpfade unter Windows 
%APPDATA%\Lastbrowser\
├── config.json         # Browser-Einstellungen & Themes
├── mcp_servers.json    # Model Context Protocol Konfigurationen
├── spaces\             # Isolierte Partitions-Daten pro Space
│   ├── default\        # Cookies, Cache, IndexedDB
│   └── work\           # Getrenntes Cookie-Jar
└── secrets\            # Mit Windows DPAPI verschlüsselte API-Keys
