# Issue #284: Änderungen nach einem Update

Stand: 27. November 2026. Der aktuelle Arbeitsstand bestimmt anhand gespeicherter Versions- und Updateinformationen, ob ein Hinweis angezeigt werden soll, und bündelt die vorhandenen lokalisierten Release-Texte offline. Für unbekannte Zielversionen wird eine allgemeine Updatebestätigung angezeigt, ohne konkrete Änderungen zu erfinden. Der Entwurf für 0.1.62 enthält in acht Sprachen drei im Arbeitszweig enthaltene Änderungen. Vor Veröffentlichung ist abzugleichen, ob sie tatsächlich im finalen Paket enthalten sind. Zusätzlich wurden kurze Einträge für [0.1.58](https://github.com/Loggableim/lastbrowser/releases/tag/v0.1.58), [0.1.59](https://github.com/Loggableim/lastbrowser/releases/tag/v0.1.59) und [0.1.60](https://github.com/Loggableim/lastbrowser/releases/tag/v0.1.60) anhand der öffentlichen Releasebeschreibungen ergänzt. Die Größenangabe zu 0.1.59 wurde zusätzlich anhand der öffentlichen Asset-Metadaten verglichen; die Ursache der Größenänderung wird nicht als unabhängig verifiziert behauptet. Für `v0.1.61` lieferte die öffentliche GitHub-Release-Abfrage 404; daraus folgt keine Aussage über mögliche Store-Veröffentlichungen. Die Einträge decken weiterhin nicht jede Tagesbeta ab.

Im Verzeichnis `apps/desktop` bestanden `node ../../node_modules/vitest/vitest.mjs run tests/release-notes.test.ts tests/update-notice-state.test.ts`: 19 Tests in zwei Dateien. Sie prüfen unter anderem Versionsbereiche, die neuen Einträge in allen acht Sprachen, frische Installationen und Updatebestätigungen; sie belegen weder die Vollständigkeit der Release-Inhalte noch einen Updatevorgang über den Microsoft Store. Draft-PR #341 besteht bereits. Issue #284 bleibt bis zur Klärung der fehlenden Einträge und einem echten Update-Nachweis offen.
