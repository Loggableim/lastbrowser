Domande Frequenti sul Download

Risposte chiare alle domande tecniche più frequenti durante l'installazione.

Perché compare l'avviso di Windows SmartScreen?

Trattandosi di una recente build open source, il binario sta consolidando la propria reputazione statistica sui server Microsoft. Puoi cliccare in tutta sicurezza su "Ulteriori informazioni" e poi su "Esegui comunque".

È supportata l'installazione silenziosa aziendale?

Sì, il setup supporta il parametro /S per installazioni automatizzate via SCCM, Intune o script PowerShell aziendali.

Come disinstallare completamente Lastbrowser?

Dalle Impostazioni di Windows > App installate, oppure eseguendo il programma di disinstallazione nella directory dell'app. I dati in %APPDATA%\Lastbrowser possono essere rimossi integralmente.

Esistono versioni per macOS o Linux?

Attualmente Lastbrowser è calibrato al 100% per Windows (ConPTY, DirectWrite, DPAPI). Le versioni per Linux e macOS sono previste nella tabella di marcia futura.
