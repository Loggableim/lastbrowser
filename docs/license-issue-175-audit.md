# Lizenzangaben: Issue 175

Stand: 26. November 2026. [Issue 175](https://github.com/Loggableim/lastbrowser/issues/175) fordert unter anderem `GPL-3.0-only` in den Paketmetadaten und einen Website-Hinweis.

- Root- und Desktop-`package.json` sowie der Lizenzabschnitt der README nennen `GPL-3.0-only` für den beschriebenen Geltungsbereich.
- `LICENSE-SCOPE.md` nennt dagegen `GPL-3.0-or-later` für berechtigte ursprüngliche LastBrowser-Bestandteile. Dieser Widerspruch besteht bereits im geprüften HEAD und wurde hier nicht aufgelöst. Die beiden [SPDX-Kennungen](https://spdx.org/licenses/GPL-3.0-only.html) unterscheiden sich in der Erlaubnis, spätere GPL-Versionen zu wählen.
- `NOTICE` verweist auf die Umfangs- und Drittanbieterhinweise; `THIRD-PARTY-LICENSES.md` dokumentiert Inventar und offene Herkunftsfragen. Deren Vorhandensein belegt keine vollständige Lizenzprüfung oder die Rechte an allen Paketbestandteilen.
- `lastbrowser.com/imprint/` verweist auf die im Repository beschriebenen Lizenzen. Das Issue nennt außerdem das separate öffentliche Repository `Loggableim/lastbrowser-website`. Dessen Stand und etwaige Änderungen müssen getrennt abgeglichen werden; hier wurde dort nichts verändert oder veröffentlicht.

Die Entscheidung über die Lizenzfassung für eigene Bestandteile liegt beim Rechteinhaber. Eine Klärung ersetzt keine Prüfung gesonderter Drittanbieterbedingungen.
