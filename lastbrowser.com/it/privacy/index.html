La Nostra Promessa: I Tuoi Dati Restano sul Tuo PC

LastBrowser non è un servizio cloud mascherato da browser. Ogni dato di sessione e richiesta di IA è elaborato e memorizzato esclusivamente in locale.

1. Principio Cardine: 100% Local-First

A differenza dei browser commerciali che sincronizzano profili, cronologia e credenziali sui server di grandi piattaforme cloud, LastBrowser rispetta scrupolosamente il paradigma Local-First.

Tutti i tuoi cookie, preferiti, cache e sessioni risiedono unicamente nella tua directory utente Windows in:

%APPDATA%\Lastbrowser\

2. Zero Telemetria Involontaria

LastBrowser non include alcun tracciatore pubblicitario, né ID di tracciamento e nessuna trasmissione automatica di telemetria. Non registriamo gli indirizzi web che consulti.

3. Crittografia Windows DPAPI

Le credenziali vengono conservate localmente e protette in base al tipo di accesso e all’integrazione configurata. Consulta anche le condizioni del provider AI collegato.

4. Flusso dei Dati con Intelligenza Artificiale (BYOK)

Quando utilizzi Sidekick, le richieste partono direttamente dal tuo computer verso il provider selezionato con la tua chiave (Bring Your Own Key) o verso la tua istanza Ollama locale. Nessun server ponte di LastBrowser memorizza o intercetta le tue chat.

5. Diritti GDPR & Controllo

Non conservando dati su server cloud terzi, il tuo diritto di accesso, esportazione o cancellazione è interamente nelle tue mani: è sufficiente cancellare la cartella locale dei dati per rimuovere ogni traccia.
