Schnellstart mit Lastbrowser

In wenigen Schritten ist Lastbrowser auf Ihrem Windows 10 oder 11 PC einsatzbereit. Erfahren Sie hier alles über die Installation und die ersten Schritte.

1. Systemanforderungen

  • Betriebssystem: Windows 10 (Version 1903 oder höher) oder Windows 11 (64-Bit x64).
  • Arbeitsspeicher: Mindestens 4 GB RAM (8 GB empfohlen für gleichzeitige LLMs & Tabs).
  • Speicherplatz: Ca. 400 MB für die Anwendungsinstallation.

2. Installation

Laden Sie das aktuelle Setup von unserer Download-Seite herunter. Führen Sie die Datei Lastbrowser-0.1.44-x64-setup.exe aus.

Hinweis zu Windows SmartScreen:

Da jede neue Open-Source-Version eine eigene Signatur besitzt, kann SmartScreen „Der Computer wurde durch Windows geschützt“ melden. Klicken Sie auf „Weitere Informationen“ und anschließend auf „Trotzdem ausführen“.

3. Die ersten Schritte im Browser

  1. Zen-Sidebar erkunden: Drücken Sie Ctrl+B, um die vertikale Seitenleiste ein- und auszublenden.
  2. Einen neuen Space erstellen: Klicken Sie in der Seitenleiste auf das + Icon bei Spaces, um einen isolierten Arbeitsbereich (z. B. „Arbeit“ oder „Recherche“) anzulegen.
  3. Nova AI Split-View öffnen: Klicken Sie auf das Nova-Symbol oder drücken Sie Ctrl+Shift+L, um den KI-Copilot im 70/30 Split-View zu starten.
  4. Terminal öffnen: Mit dem Shortcut Ctrl+\` öffnen Sie sofort das integrierte ConPTY PowerShell-Terminal.
