# High-Contrast Custom Cursors (Feature 26)

Amber `#FFC107` signal core with a 2.5px deep-black dual border — visible
>15:1 on white and black backgrounds. 4 sizes: 24px (normal), 36px (large),
48px (huge), 64px (mega). Wired via `body[data-cursor-size="..."]` in
styles.css (data-URI fallback for Chromium, which does not load external
SVG cursor files reliably).
