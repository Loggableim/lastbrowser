Unified Extension & Skill Ecosystem

Katalog der 48 Agentic Workflows & MCP

Erweitern Sie Nova AI mit spezialisierten Agentic-Skills für Recherche, Coding, Datenanalyse und Content-Erstellung oder binden Sie externe MCP-Server mit einem Klick an.

Kuratierte externe MCP-Server

Kopieren Sie die fertigen JSON-Definitionen direkt in Ihre mcp_servers.json.

🐘 PostgreSQL Database Server

Datenbank

Ermöglicht Nova AI das schreibgeschützte Abfragen von Tabellenschemata und Ausführen von SQL-Abfragen für Datenanalysen.

JSON Konfiguration 
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://user:pass@localhost/db"]
}

📂 Windows Filesystem Server

System-Tool

Erlaubt Nova AI das Durchsuchen, Lesen und Schreiben von Quellcode-Dateien in freigegebenen Projektverzeichnissen.

JSON Konfiguration 
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Projekte"]
}

🐙 GitHub Repository Tool

DevOps

Pull Requests prüfen, Issues durchsuchen und Branch-Änderungen direkt aus dem Browser analysieren.

JSON Konfiguration 
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-github"],
  "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "DEIN_TOKEN" }
}

🗺️ Google Maps Geocoding

Geo-Daten

Ermöglicht Adressprüfungen, Entfernungsberechnungen und Geocoding direkt bei der Recherche im Web.

JSON Konfiguration 
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-google-maps"],
  "env": { "GOOGLE_MAPS_API_KEY": "DEIN_KEY" }
}

Die 48 integrierten Agentic-Skills

Jeder Skill ist ein modularer Prompt- und Tool-Workflow in der in-tree Python Sidekick Engine.

🔬 1. Recherche & Analyse (12 Skills)

Paper Summarizer

PDF

Komprimiert komplexe arXiv- und ScienceDirect-PDFs auf Kernaussagen und Hypothesen.

Multi-Source Fact Checker

Web

Vergleicht Behauptungen quer über verschiedene Nachrichtenquellen und meldet Widersprüche.

Competitive Intelligence

Markt

Extrahiert Preismodelle, Feature-Tabellen und Zielgruppen von Konkurrenz-Webseiten.

Patent Analyzer

Recht

Analysiert Schutzansprüche und technische Spezifikationen in Patentdatenbanken.

💻 2. Code & Entwickler-Tools (12 Skills)

OpenAPI / Swagger Extractor

API

Erkennt API-Definitionen im DOM und generiert typisierte TypeScript-Clients oder cURL-Befehle.

Regex Visualizer & Debugger

Syntax

Erklärt reguläre Ausdrücke Schritt für Schritt und testet sie interaktiv gegen Webseiteninhalte.

Stacktrace Resolver

Doctor

Analysiert Fehlerausgaben im ConPTY-Terminal und schlägt sofortige Code-Korrekturen vor.

CSS Glassmorphism Styler

Design

Generiert moderne Tailwind- oder Vanilla-CSS Backdrop-Filter mit exakter Farb-Abstimmung.

✍️ 3. Content & Redaktion (12 Skills)

Social Thread Generator

Social

Formuliert Blogartikel in informative Twitter/X- und LinkedIn-Beiträge mit hohem Engagement um.

Executive Briefing

Management

Erstellt 1-seitige Entscheidungsvorlagen aus langen Berichten und PDF-Gutachten.

Tone & Style Adapter

Editor

Passt Formulierungen an Zielgruppen an (Akademisch, Humorvoll, C-Level, Technisch).

SEO Meta-Tag Architect

SEO

Prüft Seitentitel, Meta-Descriptions und OpenGraph-Tags auf optimale CTR.

📊 4. Daten & Tabellen (12 Skills)

HTML Table to CSV / JSON

Scraper

Wandelt Tabellen im Browser mit einem Tastendruck in saubere CSV-, JSON- oder Excel-Daten um.

JSON Schema Generator

JSON

Erstellt validierbare JSON-Schemas und TypeScript-Interfaces aus beliebigen API-Payloads.

SQL Query Optimizer

SQL

Analysiert Ausführungspläne und schlägt Indexe oder optimierte Joins vor.

Statistical Outlier Detector

Mathe

Findet Anomalien und Messfehler in numerischen Datensätzen direkt im Browser-Speicher.
