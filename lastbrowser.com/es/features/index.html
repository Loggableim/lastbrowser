Los 5 Pilares Fundamentales de Lastbrowser

Construido desde cero para resolver las limitaciones de los navegadores convencionales.

💻

1. Terminal ConPTY Nativo

Una pseudoconsola completa de Windows en la barra lateral (Ctrl+\`). Ejecuta PowerShell, CMD, Git, scripts de Python o gestiona modelos locales sin salir de la pestaña activa.

🪐

2. Espacios Aislados

Aislamiento total de cookies, cachés y almacenamiento local por Espacio mediante persist:profile:space. Inicia sesión en múltiples cuentas del mismo servicio simultáneamente.

🤖

3. Nova AI y Modelo BYOK

IA totalmente configurable: Gemini CLI Multi-Account, Claude 3.5, OpenAI o 100% offline con Ollama. Cero suscripciones cloud forzosas y control total de privacidad.

🎬

4. Streaming DRM y Audio

Módulo oficial Castlabs Widevine CDM integrado. Reproduce contenido protegido en Full HD en Netflix, Disney+, Prime Video y Spotify sin errores.

⚡

5. Hub MCP y 48 Agentes

Combina extensiones Chrome MV3 con 48 agentes especializados y servidores Model Context Protocol (PostgreSQL, Filesystem, GitHub).

🛡️

Privacidad 100% Local-First

Tus contraseñas, historial y tokens de API nunca se transmiten a servidores externos. Cifrado local con Windows DPAPI en %APPDATA%\Lastbrowser.
