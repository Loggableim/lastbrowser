Nuestra Promesa: Tus Datos se Quedan en tu PC

Lastbrowser no es un servicio en la nube disfrazado de navegador. Toda tu información se procesa y almacena localmente en tu ordenador.

1. Principio Fundamental: 100% Local-First

A diferencia de los navegadores convencionales que sincronizan perfiles, historiales de navegación y credenciales en servidores centralizados de Google o Microsoft, Lastbrowser opera bajo el estricto paradigma Local-First.

Toda tu actividad, historial de pestañas, caché, contraseñas y claves de API residen exclusivamente en tu sistema operativo local en:

%APPDATA%\Lastbrowser\

2. Cero Telemetría Involuntaria

Lastbrowser no contiene rastreadores, identificadores publicitarios ni sistemas de telemetría de uso. No recopilamos informes de errores automatizados sin tu consentimiento expreso ni registramos las URL que visitas.

3. Cifrado Nativo Windows DPAPI

Las claves de API de tus proveedores de IA (Gemini, Claude, OpenAI) y las credenciales web se cifran mediante la interfaz Windows Data Protection API (DPAPI). Solo tu cuenta de usuario autenticada en tu PC puede desencriptar estos secretos locales.

4. Flujo de Datos con Inteligencia Artificial (BYOK)

Cuando utilizas Nova AI, las peticiones van directamente desde tu navegador al proveedor que configures con tu propia clave (Bring Your Own Key) o a tu instancia local de Ollama. No existe ningún servidor intermedio de Lastbrowser que intercepte tus conversaciones.

5. Derechos de Protección de Datos (RGPD / DSGVO)

Dado que Lastbrowser no recopila ni almacena datos personales en servidores externos, el control de acceso, modificación o supresión de datos está al 100% en tus manos: basta con borrar la carpeta de datos de tu disco duro para eliminar todo rastro.
