Perguntas Frequentes sobre o Download

Esclarecimentos diretos para as dúvidas técnicas mais comuns durante a instalação.

Por que o Windows SmartScreen exibe um alerta?

Por se tratar de uma nova versão de código aberto recente, o arquivo ainda está acumulando reputação junto à Microsoft. Clique com segurança em "Mais informações" e depois em "Executar assim mesmo".

A distribuição corporativa silenciosa é suportada?

Sim, o instalador suporta o parâmetro /S para automações com SCCM, Intune ou scripts PowerShell corporativos.

Como desinstalar o Lastbrowser completamente?

Pelas Configurações do Windows > Aplicativos instalados, ou pelo desinstalador na pasta do programa. Os dados de %APPDATA%\Lastbrowser podem ser apagados integralmente.

Existem versões para macOS ou Linux?

No momento o Lastbrowser é focado e calibrado na arquitetura do Windows (ConPTY, DirectWrite, DPAPI). Versões para Linux e macOS constam no roteiro futuro.
