Tastaturkürzel Cheat-Sheet

Steuern Sie Lastbrowser blitzschnell ohne Maus. Alle Hotkeys sind für Windows optimiert.

Tastenkombination Aktion / Funktion Kategorie
Ctrl + B Vertikale Sidebar ein- oder ausblenden (Vollbild-Lesemodus) Sidebar
Ctrl + ` ConPTY PowerShell-Terminal ein- oder ausblenden Terminal
Ctrl + Shift + L Nova AI Copilot im 70/30 Split-View ein- oder ausblenden KI / Nova
Ctrl + Shift + X Unified Extension & MCP Hub öffnen Erweiterungen
Ctrl + T Neuen Tab im aktiven Space öffnen Tabs
Ctrl + W Aktiven Tab schließen Tabs
Ctrl + Shift + T Zuletzt geschlossenen Tab im aktiven Space wiederherstellen Tabs
Ctrl + Tab Zum nächsten geöffneten Tab wechseln Tabs
Ctrl + 1 ... 9 Direkt zu Tab 1 bis 9 im aktiven Space springen Tabs
Ctrl + L Adress- und Suchleiste (Omnibox) fokussieren Navigation
Ctrl + R Aktuelle Seite neu laden Navigation
Ctrl + F Inhalts-Suchleiste auf der aktuellen Seite öffnen Suche
F12 Chromium DevTools Inspektor öffnen Entwickler
