Sicherheits- & Datenschutz-Architektur

Lastbrowser wurde von Grund auf nach dem Prinzip „Local-First by Design“ entwickelt. Alle sensiblen Daten verbleiben auf Ihrem Endgerät und werden durch bewährte Windows-Sicherheitstechnologien geschützt.

🛡️

1. Multi-Process Architecture & Sandboxing

Lastbrowser nutzt die erprobte Chromium Multi-Process Architektur. Jeder geöffnete Web-Tab läuft in einem separaten, isolierten Renderer-Prozess mit striktem Betriebssystem-Sandboxing. Kompromittierte Webseiten können weder auf das Dateisystem noch auf andere Tabs oder das ConPTY-Terminal zugreifen.

🔑

2. Lokale DPAPI-Verschlüsselung

Alle sensiblen Daten (gespeicherte Passwörter, Cookie-Jars und API-Schlüssel für Gemini, Claude oder OpenAI) werden in %APPDATA%\Lastbrowser mit der Windows Data Protection API (DPAPI) verschlüsselt. Die Entschlüsselung ist kryptografisch an Ihr Windows-Benutzerkonto gebunden und kann von anderen Windows-Nutzern oder exportierten Dateisystemen nicht gelesen werden.

🚫

3. Zero Involuntary Telemetry

Im Gegensatz zu herkömmlichen Browsern enthält Lastbrowser keinerlei Tracking-Bibliotheken, keine Google Analytics-Skripte und keine Werbenetzwerke. Es werden keine Webseitenverläufe, Klicks oder Suchanfragen im Hintergrund übertragen. Die einzige Kommunikation nach außen erfolgt bei expliziter Nutzeraktion (z. B. Prüfen auf neue Updates via GitHub Releases).

⚖️

4. Microsoft Store Generative AI Policy 10.2 Compliance

Zur Einhaltung der Richtlinien des Microsoft Stores implementiert Lastbrowser integrierte Mechanismen zur Berichterstattung unerwünschter KI-Inhalte. Nutzer können problematische Antworten im Chat jederzeit über ein Melde-Formular kennzeichnen und die Mentalität des Copiloten anpassen.
