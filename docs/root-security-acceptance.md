## Findings

| Criterion | Status | Current evidence and remaining gap |
|---|---|---|
| A16 Stop while work is running | **Pass (deterministic backend race)** | `RunManager._control` transitions the run, closes its target, terminates the worker, and marks in-flight actions unknown (`services/sidekick/runtime/independent/manager.py:1141–1205`). New `test_root_security_late_gateway_success_cannot_resurrect_stopped_run` blocks a browser action inside the gateway, waits for acknowledged cancel, then releases a simulated late success. The terminal run stays cancelled, the action stays `unknown`, and only one gateway call occurred. Existing late worker-result test also passes. Live packaged Stop and real external effect reconciliation remain unverified. |
| A17 Approval binds scope, target, epoch, and exact arguments | **Pass (deterministic tests)** | `ApprovalView` now serializes action ID, lease ID, target ID, Main/runner generations, navigation epoch, control epoch, permission revision, scope and canonical argument digest (`runtime/independent/contracts.py:506–523`). `create_approval` compares it to the exact prepared action (`store.py:626–650`); `RunManager.approve` checks the live gateway snapshot against run/scope/lease/target/generations/navigation epoch (`manager.py:257–303`); `_refresh_action_browser_identity` rechecks before claim and immediately before gateway dispatch (`manager.py:950–969`, `1020–1032`); and `claim_action` compares the exact persisted lease and consumed approval (`store.py:729–775`). Lease navigation updates require all owner/target generations to stay fixed and navigation epoch to be monotonic (`store.py:999–1022`). Legacy target-bound approvals without action identity cannot be approved (`store.py:655–684`). Our strict target replacement test and four lease/target/generation mutation tests pass, as does an unchanged-identity exact-action dispatch test. This is deterministic manager/store/gateway evidence; live browser behavior remains unverified. |
| A18 Connection revoke versus dispatch | **Pass (deterministic backend race)** | `store.claim_action` checks captured bindings against active repository rows in its transaction (`runtime/independent/store.py:729–775`); repository revocation commits `revoking` plus permission revision before Main acknowledgment (`runtime/independent/connections.py:92–107`). New `test_root_security_connection_revoke_fences_inflight_gateway_success` waits until a bound browser read enters the gateway, commits connection revocation, waits for Manager acknowledgment, then releases a simulated late success. Run stays interrupted, journal stays `unknown`, and there is one dispatch only. Cross-process live Main dispatch remains unverified. |
| A25 Manipulative page text | **Partial (backend contract passed)** | Human control parsing rejects page provenance and quoted/question text (`assistant_controls.py:48–110`); model delegation is gated by human input (`assistant.py:36–42, 351–364`), and selected page data is marked untrusted (`assistant.py:346–347`). Existing `test_selected_page_instructions_never_supply_control_authority` passes with a page body containing an exact `stop <runId>` imperative; page provenance, injected model claims, and a capability question do not create control candidates. No real browser-to-assistant page-selection flow was exercised. |
| A32 Spoofed IPC, foreign target, raw CDP | **Partial (boundary tests passed)** | Shell IPC checks registered shell identity, main frame, and trusted preload URL (`apps/desktop/src/main/ipc-sender.ts:6–28`); controller captures/rechecks sender (`independent-controller.ts:453–459, 720–733`). New `test_root_security_live_run_cannot_use_raw_cdp_or_select_foreign_target` pre-creates a live lease, then submits both `browser_cdp` with Runtime.evaluate and a read action carrying a known foreign target ID; both raise `PolicyDenied` with zero gateway actions. Existing Electron sender/frame, raw-CDP and foreign-target cases are in the focused suite. No malicious live renderer or packaged IPC attack was run. |
| A33 File roots, junctions, UNC, no shell | **Partial (Windows path tests passed)** | New `test_root_security_workspace_junction_cannot_escape_to_sibling_tree` creates a temporary Windows directory junction from an allowed workspace to an outside sibling, then proves both canonical native-chat path checks and independent authorized reads deny it; the outside sentinel remains unchanged. `test_root_security_unc_path_is_rejected_before_network_or_file_access` passes a synthetic UNC path to the path canonicalizer and denies it before network access. Existing tests also verify stale assistant replies cannot add a late task, and Manager dispatch reserves idempotently. The new A16 gateway race proves a late successful effect response after stop cannot transition the unknown action or terminal run back to success. No live UI lost/duplicated result presentation was exercised; separate old projection tests had `worker_ended` before their assertion. |
| A51 Selected page context | **Partial** | Main accepts selected references through frame-bound validation and revalidates them after startup recovery (`independent-controller.ts:658–733`); assistant input labels selected page text untrusted (`assistant.py:346–347`). | A52 Existing Copilot/chat preservation | **Unverified** | Existing normal session IDs/content remain in the ordinary chat/store path, and `native-chat-stream-controller.ts` binds stream receipts to captured sessions/profiles. These are deterministic manager workers, not two simultaneous live browser tasks. |
