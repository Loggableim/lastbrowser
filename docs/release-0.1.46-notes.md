# Lastbrowser 0.1.46 – Release Notes (Entwurf)

## Änderungen

- **Fokusmodus schneller erreichbar:** Das kompakte NovaDock bietet jetzt einen direkten, lokalisierten Zugang zum Zen-/Fokusmodus.
- **Quickchat unter Windows:** Der Quickchat-Start wurde korrigiert.
- **Manuelle Modellwahl:** Teamwork-Modelle können in der manuellen Modellauswahl gewählt werden.
- **Sicherere Statusabfragen:** Authentifizierungsstatus-Abfragen bleiben unverändert lesend.
- **Entwurfsqualität:** Reine Reasoning-Ausgaben werden nicht mehr als fertige Antwortentwürfe übernommen.

## Einschränkungen

- Der lokale Router bleibt experimentell und ist nicht als qualifiziert einzustufen.
- Eine echte Teamwork-Abnahme mit drei Providern wurde nicht durchgeführt; diese Notes behaupten keine solche Bestätigung.

Diese Notizen sind ein Offline-Entwurf und keine Veröffentlichungsaussage.
