LastBrowser — ru-RU

DESCRIPTION
LastBrowser — браузер на базе Chromium для Windows с вертикальными вкладками и рабочими пространствами. Включаемый по желанию помощник Nova использует генеративный ИИ, чтобы создавать ответы на ваши запросы.

Возможности:
• Вертикальные вкладки и рабочие пространства для ваших веб-проектов.
• ИИ-помощник Nova для вопросов, кратких изложений и работы с предоставленным вами контекстом веб-страниц.
• Подключайтесь со своими учетными данными к проверенным и квалифицированным сочетаниям поставщика и модели ИИ; локальные модели Ollama могут быть доступны. Непроверенные бета-сочетания скрыты по умолчанию и, если предлагаются, требуют явного включения в настройках.
• Встроенный терминал и поддержка расширений браузера.
• Локальное хранение профилей браузера и инструменты для удаления данных просмотра.
• В чатах по умолчанию используется одна модель. Оркестрация Teamwork — бета-функция, включаемая пользователем.

LastBrowser можно скачать бесплатно. Внешние ИИ-сервисы могут требовать учётную запись и оплату. При использовании внешнего поставщика ИИ ему отправляются ваш запрос и предоставленный вами контекст задачи. Профили браузера хранятся локально на вашем ПК. Продолжают действовать лицензии и условия сторонних компонентов, моделей и внешних сервисов.
SHORT DESCRIPTION
Браузер Chromium для Windows с вертикальными вкладками, рабочими пространствами и помощником Nova, которого можно включить по желанию. Профили хранятся на ПК. Внешние ИИ-сервисы получают запросы и материалы, которые вы предоставляете для задачи.
