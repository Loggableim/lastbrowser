Häufige Fragen zur Installation

Warum meldet Windows SmartScreen „Unbekannter Herausgeber“?

Da Lastbrowser als Open-Source-Projekt kontinuierlich neue Releases ausliefert, benötigt jede neue Binärdatei einige Tage, um bei Microsoft die sogenannte SmartScreen-Reputation aufzubauen. Die Datei ist digital signiert und absolut sicher. Klicken Sie einfach auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.

Wo speichert Lastbrowser meine Benutzerdaten?

Alle Browserprofile, Spaces, ConPTY-Konfigurationen und API-Schlüssel werden ausschließlich lokal auf Ihrem System im Verzeichnis %APPDATA%\Lastbrowser gespeichert. API-Schlüssel werden über die native Windows Data Protection API (DPAPI) verschlüsselt.

Wie führe ich eine stille Installation (Silent Setup) aus?

Systemadministratoren können den Installer mit dem Parameter /S silent im Hintergrund installieren, ohne dass Benutzeroberflächen oder Abfragen erscheinen: Lastbrowser-0.1.53-x64-setup.exe /S.

Funktioniert Widevine DRM Streaming (Spotify, Netflix)?

Ja. Lastbrowser integriert Castlabs Electron Widevine CDM L3. Geschützte Medienstreams auf Spotify, Netflix, Disney+ und Prime Video funktionieren out-of-the-box.
