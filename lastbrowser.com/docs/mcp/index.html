Model Context Protocol (MCP) in Lastbrowser

Das Model Context Protocol (MCP) ist ein offener Standard, der es KI-Assistenten erlaubt, sicher mit externen Datenquellen, Dateisystemen und Entwickler-Tools zu interagieren. Lastbrowser unterstützt MCP nativ im Sidekick-Engine-Kern.

Konfigurationsdatei: mcp_servers.json

MCP-Server werden in der Datei %APPDATA%\Lastbrowser\mcp_servers.json definiert. Jedes Tool, das über stdio oder SSE kommuniziert, kann angebunden werden:

mcp_servers.json 
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://localhost/mydb"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "DEIN_TOKEN"
      }
    }
  }
}

Wie Nova AI mit MCP-Tools interagiert

  1. Tool Discovery: Beim Start fragt die Sidekick-Engine die verfügbaren Fähigkeiten des MCP-Servers ab (tools/list).
  2. Kontextuelle Auswahl: Wenn Sie Nova eine Frage stellen (z. B. „Zeige mir die letzten 5 Commits im Repo“), wählt Nova das entsprechende GitHub-Tool automatisch aus.
  3. Menschliche Bestätigung: Sensible Aktionen (Schreibvorgänge auf die Festplatte oder SQL-Updates) fordern vor Ausführung eine Nutzerbestätigung im Chat.
