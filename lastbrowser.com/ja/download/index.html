ダウンロード・インストールに関するFAQ

セットアップ時に寄せられるよくある質問への回答です。

Windows SmartScreenの警告が表示されるのはなぜですか？

リリースされたばかりのオープンソースソフトウェアであるため、Microsoftのクラウド上でダウンロード実績（評価）が蓄積途中の状態です。「詳細情報」をクリックし、「実行」を選択して問題なく続行できます。

企業向けのサイレント（一括）展開は可能ですか？

はい。インストーラーは/Sスイッチをサポートしており、SCCM、Intune、PowerShellスクリプトによる無人展開が可能です。

アンインストールはどのように行いますか？

Windowsの「設定 > インストールされているアプリ」またはプログラムフォルダー内のアンインストーラーから削除できます。%APPDATA%\Lastbrowser内の個人データもきれいに消去されます。

macOS版やLinux版はありますか？

署名済み Linux x64 パッケージです。AppImage を実行するか、tar.gz アーカイブを展開してください。 macOS 版は準備中です。

Windows SmartScreen警告の解除方法

大規模なクラウド追跡を持たない最新のオープンソースバイナリのため、Windows SmartScreenにより青い警告画面が表示される場合があります：

ステップ 1: 青いダイアログ内の 「詳細情報」 をクリックします。

ステップ 2: 右下に現れる 「実行」 ボタンをクリックします。

ダウンロードしたファイルのSHA-256ハッシュとデジタル署名を確認できます。
