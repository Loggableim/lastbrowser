Integriertes ConPTY Windows Terminal

Lastbrowser bindet die moderne Windows Pseudo-Console (ConPTY) direkt in die Browser-Shell ein. Entwickler erhalten ein echtes Terminal mit voller ANSI-Farbunterstützung, xterm.js Rendering und PowerShell Core Unterstützung.

Terminal öffnen & steuern

  • Ctrl + ` : Terminal Drawer öffnen / minimieren
  • Ctrl + Shift + C : Markierten Text im Terminal kopieren
  • Ctrl + Shift + V : Text in das Terminal einfügen

Unterstützte Shells

Standardmäßig startet Lastbrowser die native 64-Bit PowerShell.exe. In den Einstellungen können Sie die bevorzugte Shell frei wählen:

  • PowerShell 7 (pwsh.exe) (sofern installiert)
  • Windows PowerShell 5.1 (Standard auf allen Windows 10/11 Systemen)
  • Eingabeaufforderung (cmd.exe)
  • Windows Subsystem for Linux (wsl.exe)
