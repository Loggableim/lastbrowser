I 5 Pilastri Fondamentali di Lastbrowser

Progettato per superare i limiti storici dei browser tradizionali.

💻

1. Terminale ConPTY Nativo

Una vera pseudo-console Windows integrata nella barra laterale (Ctrl+\`). Esegui PowerShell, CMD, Git, script Python o gestisci modelli locali senza abbandonare la pagina attiva.

🪐

2. Spazi Isolati

Separazione rigorosa di cookie, cache e memoria locale per Spazio tramite persist:profile:space. Accedi a più account dello stesso servizio in simultanea.

🤖

3. Nova AI & Modello BYOK

IA completamente configurabile: Gemini CLI Multi-Account, Claude 3.5, OpenAI o modelli locali offline con Ollama. Nessun abbonamento forzato, totale rispetto della privacy.

🎬

4. Streaming DRM & Audio

Modulo ufficiale Castlabs Widevine CDM preinstallato. Riproduzione Full HD fluida dei contenuti protetti su Spotify, Netflix, Disney+ e Prime Video.

⚡

5. Hub MCP & 48 Agenti

Unisci la ricchezza delle estensioni Chrome MV3 con 48 flussi di agenti e server Model Context Protocol (PostgreSQL, Filesystem, GitHub).

🛡️

Privacy 100% Local-First

Password, cronologia e token API non transitano mai su server cloud esterni. Tutto risiede in locale in %APPDATA%\Lastbrowser protetto da crittografia DPAPI.
