## Provider und Testbegrenzung

Zu Beginn war `openai-codex` aktiv, der Settings-Katalog zeigte drei Gruppen und keinen Default. Die UI bot **GPT 6 Luna**, Google-Flash-Modelle und Ollama Cloud **Deepseek V4.1 Flash** an. OpenAI Codex zeigte dennoch eine **Connect**-Aktion. Es wurde keine Anmeldung automatisiert und kein Schlüssel gelesen oder eingegeben. [Katalog](evidence-0.1.46-ui-2026-10-06/02-provider-catalog-no-default.png), [GPT-Karte](evidence-0.1.46-ui-2026-10-06/03-gpt-active-connect.png).

Der eingerichtete Google-Account war sichtbar; seine Accountdaten wurden nicht in Evidence übernommen. Antigravity wurde über **Use** aktiviert, der Conversation-Default über die UI auf **Gemini 2.5 Flash** gesetzt. Der Default-Fallback blieb **none**. Für GPT wurde ausschließlich **GPT 6 Luna** angefragt, keine größeren GPT-Modelle.

Teamwork wurde für den kleinen Test explizit auf **Gemini 2.5 Flash** begrenzt: Planner, Workerpool, Critic und Synthesizer. **Try another model if one fails** ausgeschaltet; **Resource-saving** gewählt; **Save** führte zu **Saved**. [Rollen-/Workerauswahl](evidence-0.1.46-ui-2026-10-06/05-teamwork-google-flash-roles.png). Es gab keinen absichtlichen Mehrprovider- oder Lasttest.

**Wichtig:** Angebotslisten und gespeicherte Einstellungen sind kein Nachweis nutzbarer Modelle. Die folgenden UI-Versuche lieferten keine erfolgreiche Modellantwort. Eine serverseitige Ausführung, Abrechnung oder erfolgreiche Authentifizierung ist dadurch nicht belegt.

Die von AGENTS.md vorgeschriebenen Befehle wurden versucht. `npm test`, `npm run verify:store` und `npm --workspace apps/desktop run build` sind **blockiert**, weil `npm`/`npm.cmd` im Guest fehlt; auch `node_modules` fehlt. Keine Abhängigkeiten installiert und keine Produktdateien geändert. Diese Quellcode-Prüfungen ersetzen keine UI-Abnahme des installierten Pakets.

## Verbleibende Voraussetzungen (aktualisiert)

- Upgrade-/Änderungs-Popup: **nicht geprüft**, da kein dafür gesondert freigegebener passender Kandidat vorliegt; laut Auftrag folgt dieser Test separat.
- Nutzbare, zum ausgewählten Provider und Space gebundene Modelle bzw. ein korrigierter separater Kandidat sind nötig, bevor echte Antworten, Streaming-Stop, Teamwork-Beiträge/Stop und erfolgreiche Quickchat-Sessionpersistenz abgenommen werden können. Die UI-Kataloge allein reichen nicht.
- Der normale vollständige Neustart für die Namenspersistenz ist offen; Nutzeraktion wurde angefragt. Alle bereits gesicherten Befunde gehören zu diesem unverändert installierten 0.1.46-Testpaket. Ein neues Paket bekommt einen eigenen Hash und Bericht.
- Keine Anmeldedaten, Accountidentitäten oder Schlüssel in den veröffentlichten Screenshots. Bestehende synthetische Testspaces und Testeinstellungen bleiben erhalten. Produktquellen wurden nicht repariert.

Dieser Bericht meldet keine erfolgreiche Modellantwort und keinen erfolgreichen Stop. Er ist eine UI-Nachprüfung mit expliziten Fehlern und Blockaden; die offenen Abnahmekriterien bleiben offen.
