What's New in Lastbrowser?

All updates, performance improvements, new features, and the upcoming development roadmap at a glance.

v0.1.33 Current Beta Release
September 25, 2026

Feature & Stability Update: Google OAuth Safe Login, Teamwork & Smart Track Multi-Agent Orchestration, Zen Hover Reveal, Space Setup Assistant, and Dock Fisheye Animation.

  • Google OAuth Hardening: Seamless, secure Google authentication preventing the "Browser or app may not be secure" block via native Chrome 134 emulation, Client Hints, and X-Requested-With stripping.
  • Teamwork & Smart Track Orchestrator: Multi-model collaborative agent team (Lead, Researcher, Analyst, Critic) and single-lane token-efficient Smart Track mode with adaptive effort tiers (Low, Medium, High).
  • Zen Mode Hover Reveal: 8px left edge hover zone smoothly slides the sidebar into view as a floating overlay without displacing web page layout.
  • Dock Fisheye & Hover Titles: Fluid macOS-inspired dock fisheye effect with dynamic scaling and progressive dimming of adjacent icons in slim dock mode.
  • Space Setup Assistant: 3-step creation wizard for new spaces with presets (Coding, Research, Media, Blank), accent colors, and custom AI model routing.
  • Downloads Overlay & Floating Dock: Detachable downloads panel with persistent screen positioning, pill minimization, and multiple docking slots.
  • Instant Live Auto-Save: Theme, font size, page zoom, and notification preferences now persist instantly with zero delay without a separate save button.
v0.1.32 September 25, 2026

Major Milestone: 100% Space Session Isolation, Space Hub Start Page, Castlabs Widevine VMP Signing & EV Authenticode.

  • 100% Space Session Isolation: Each Space now maintains an independent partition key (persist:profile:space). Logins for Google, Disney+, or GitHub are strictly isolated between Spaces with zero session spillover.
  • Space Hub Dashboard: New Space section on the start page displaying active Spaces, live tab counters, quick switching, and an inline "+ New Space" creation modal.
  • Castlabs Widevine DRM: Complete integration with Castlabs Electron and Video Multi-Part Protection (VMP) code signing. Netflix, Disney+, Spotify, and Prime Video stream reliably with full hardware acceleration.
  • Split-View Rendering Fixes: Smooth tab switching between dual-tab split-view and standard tabs without stuck rendering states.
  • Extended Validation (EV) Code Signing: All release binaries (NSIS Setup & Portable) are officially signed and timestamped under Dominik Rainer (Certum CA).
  • Complete Test Verification: 71 Vitest suites with 625 tests passing; 27/27 Microsoft Store preflight checks green.
v0.1.31 September 24, 2026
  • Unified Extension & Skill Hub: Chrome MV3 WebExtensions and external MCP servers united under a single hotkey (Ctrl+Shift+X).
  • Modern Popart Icons: High-resolution 32px & 64px vector icons across the sidebar navigation.
  • Grounding Anchors: In-page text highlights when Nova AI performs cross-tab synthesis.
v0.1.30 September 22, 2026
  • Multi-Account Gemini CLI: Cyclic load balancing and automatic failover on quota limits (HTTP 429) with real-time status badges.
  • ConPTY PowerShell Terminal: Full Windows PowerShell terminal inside the browser sidebar with interactive agent TUI and doctor self-repair command.
  • Smart Tab Discarding: Automated tab hibernation to dramatically reduce RAM and power usage.
