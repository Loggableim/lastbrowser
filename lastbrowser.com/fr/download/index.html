Questions Fréquentes sur le Téléchargement

Réponses aux questions techniques courantes lors de l'installation.

Pourquoi Windows SmartScreen affiche-t-il une alerte ?

En tant que nouvelle version Local-First récemment publiée, le binaire n'a pas encore cumulé une réputation statistique chez Microsoft. Cliquez sur "Informations complémentaires" puis "Exécuter quand même".

Le déploiement silencieux en entreprise est-il supporté ?

Oui, l'installateur accepte le paramètre /S pour une installation automatisée via SCCM, Intune ou scripts PowerShell.

Comment désinstaller LastBrowser proprement ?

Via les Paramètres Windows > Applications installées, ou via l'utilitaire de désinstallation du dossier du programme. Les données locales dans %APPDATA%\Lastbrowser peuvent être effacées intégralement.

Des versions pour macOS ou Linux existent-elles ?

LastBrowser est actuellement optimisé pour l'écosystème Windows (ConPTY, DirectWrite, DPAPI). Les versions Linux et macOS figurent sur notre feuille de route.
