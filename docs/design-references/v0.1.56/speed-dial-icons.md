# v0.1.56 Schnellstart-Icons

Die Schnellstart-Karten laden ihre Icons aus `brand/assets/speed-dial/`. Ein Öffnen der leeren Startseite fragt damit keine fremden Favicons ab. Ein Netzwerkaufruf zu einer Zielseite erfolgt erst, wenn der Nutzer sie öffnet.

Die Dateien wurden am 12. Oktober 2026 von den folgenden Quellen in den Repository-Bestand übernommen:

| Datei | Quelle |
| --- | --- |
| `github.ico` | `https://github.com/favicon.ico` |
| `google.ico` | `https://www.google.com/favicon.ico` |
| `wikipedia.ico` | `https://en.wikipedia.org/favicon.ico` |
| `youtube.ico` | `https://www.youtube.com/favicon.ico` |
| `reddit.png` | `https://www.reddit.com/favicon.ico` (Antwortformat PNG) |
| `hackernews.ico` | `https://news.ycombinator.com/favicon.ico` |
| `huggingface.ico` | `https://huggingface.co/favicon.ico` |
| `openai.svg` | `https://commons.wikimedia.org/wiki/File:OpenAI_logo_2025_(symbol).svg` (Originaldatei; dort als geometrisches Logo und Marke gekennzeichnet) |

Die Logos dienen ausschließlich als Kennzeichen der jeweiligen Verknüpfungen. Marken- und Nutzungsrechte dieser Dateien sind vor einer öffentlichen Auslieferung zu prüfen; ihre Aufnahme in den Draft ist keine Freigabe.
