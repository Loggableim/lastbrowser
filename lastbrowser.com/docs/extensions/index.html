Chrome MV3 Erweiterungen & Dev Guide

Lastbrowser basiert auf der Chromium-Engine und unterstützt den modernen Chrome Extension Manifest V3 (MV3) Standard vollständig. Sie können Ihre Lieblings-Erweiterungen (uBlock Origin, Bitwarden, React Developer Tools etc.) direkt nutzen.

Installation aus dem Chrome Web Store

Öffnen Sie den offiziellen Chrome Web Store in Lastbrowser und klicken Sie wie gewohnt auf „Hinzufügen“. Lastbrowser bindet die Erweiterung in die native Menüleiste ein.

Entpackte Erweiterungen laden (Entwickler-Modus)

Für Extension-Entwickler bietet Lastbrowser einen schnellen Reload-Zyklus für entpackte Verzeichnisse:

  1. Drücken Sie Ctrl + Shift + X, um den Unified Extension Hub zu öffnen.
  2. Aktivieren Sie den Schalter „Entwicklermodus“.
  3. Klicken Sie auf „Entpackte Erweiterung laden“ und wählen Sie den Ordner mit Ihrer manifest.json aus.

Unterstützte Chrome APIs

Lastbrowser implementiert den Chromium-Standard inklusive:

  • chrome.runtime, chrome.tabs, chrome.storage
  • chrome.declarativeNetRequest (effizientes Werbe- und Tracking-Blocking)
  • chrome.contextMenus, chrome.action
  • chrome.cookies (unter Beachtung der aktiven Space-Partition)
