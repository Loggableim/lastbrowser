Built for Software Engineers & DevOps

Der Browser, der wie eine IDE denkt

Schluss mit dem ständigen Alt-Tab zwischen Dokumentation, Web-App und Terminal. LastBrowser integriert ein echtes ConPTY Windows-Terminal, OpenAPI-Extraktoren und Model Context Protocol (MCP) direkt in den Browser.

LastBrowser für Entwickler herunterladen Terminal-Dokumentation lesen
💻

Echtes ConPTY Terminal

Ein vollwertiges Windows Pseudo-Terminal in der Seitenleiste. Führen Sie git, npm, cargo oder docker direkt neben laufenden Localhost-Apps aus (Ctrl+\`).

🩺

Terminal Doctor

Automatische Fehlerdiagnose bei fehlgeschlagenen Builds oder Stacktraces. Der integrierte Doctor analysiert Fehlermeldungen und schlägt Reparatur-Befehle vor.

🔌

Model Context Protocol (MCP)

Verbinden Sie lokale und externe MCP-Server (PostgreSQL, Filesystem, GitHub) mit einem Klick. Geben Sie der KI direkten Zugriff auf Ihre Entwickler-Werkzeuge.

🦙

100% Offline via Ollama

Arbeiten Sie offline im Flugzeug oder in Hochsicherheitsnetzen. Binden Sie lokale Ollama-Modelle (Llama 3, DeepSeek Coder, Qwen) latency-frei ein.

📄

OpenAPI & GraphQL Extraktor

Sidekick erkennt API-Dokumentationen auf Webseiten automatisch und exportiert saubere TypeScript-Typen, curl-Befehle oder Postman-Collections.

🪐

Isolierte Localhost-Spaces

Testen Sie Frontend und Backend unter verschiedenen Authentifizierungsrollen gleichzeitig auf localhost:3000, ohne Cookies manuell löschen zu müssen.

1-Klick MCP Server Anbindung

Konfigurieren Sie MCP-Server in Ihrer mcp_servers.json direkt unter %APPDATA%\Lastbrowser:

mcp_servers.json 
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://localhost/mydb"]
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Projekte"]
    }
  }
}
