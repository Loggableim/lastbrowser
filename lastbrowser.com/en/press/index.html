Key features

Sidekick in split view

Work with the built-in AI assistant Sidekick in a split view next to the page you are reading.

Your keys or local models

Bring your own API keys or run local models via Ollama. Your data stays on your machine by default.

Spaces

Every Space has its own isolated profile with separate cookies, storage and cache.

Zen Mode

Hides the tab sidebar for a distraction-free view.

Accessibility magnifier

Magnifier with 1.5–4x zoom (Ctrl+Shift+L).

Ad and tracker blocker

Built-in blocking based on EasyList and EasyPrivacy.

Streaming

Netflix and other streaming services work (Widevine DRM).

Built-in terminal

PowerShell, cmd or WSL, off by default.

MCP Hub

About LastBrowser

LastBrowser is a free desktop browser for Windows and Linux (Linux preview) built by Austrian developer Dominik Rainer as a one-person project. It combines isolated Spaces, a distraction-free Zen Mode and the built-in AI assistant Sidekick, which works with your own API keys or with local models via Ollama. LastBrowser has no telemetry and needs no account.
