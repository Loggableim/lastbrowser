Quali elementi vorresti sostenere?

Usa il pulsante per sostenere più elementi e ritirare il voto in qualsiasi momento. I totali sono condivisi tra i visitatori.

Non serve un account. Il cookie funzionale viene creato solo al primo voto. Un voto per elemento e browser viene conservato per un massimo di un anno.

I voti aiutano a definire le priorità e non garantiscono una data di rilascio.

Come superare la schermata di Windows SmartScreen

Essendo una nuova versione open source senza telemetria cloud di massa, Windows SmartScreen può mostrare un avviso blu preventivo:

Passaggio 1: Fai clic sul link "Ulteriori informazioni".

Passaggio 2: Fai clic sul pulsante "Esegui comunque" in basso.

Puoi verificare l'impronta SHA-256 e la firma digitale del file scaricato.
