Local-First 設計 · 100% GDPR準拠

私たちの約束： あなたのデータはお使いのPCに残ります

Lastbrowserはブラウザの皮を被ったクラウドサービスではありません。閲覧履歴やAI処理データはすべてローカル環境内で厳重に処理・保持されます。

1. 基本原則：100% Local-First（ローカルファースト）

ユーザープロファイル、閲覧履歴、認証情報をクラウドサーバーへ強制同期させる従来の商用ブラウザとは異なり、Lastbrowserは完全なLocal-Firstアーキテクチャを採用しています。

すべてのCookie、キャッシュ、パスワード、APIトークンはお使いのWindows PC内の専用フォルダーにのみ保存されます：

%APPDATA%\Lastbrowser\

2. 不本意なテレメトリゼロ

Lastbrowserには広告トラッカー、隠しアナリティクスID、無断でデータを吸い上げるテレメトリ機能は一切組み込まれていません。アクセスしたWebサイトのURLを当社サーバーへ送信することはありません。

3. Windows DPAPI ネイティブ暗号化

AIプロバイダー（Gemini、Claude、OpenAI）のAPIキーや保存パスワードは、Windows Data Protection API (DPAPI)によってハードウェアキーと連携して強力に暗号化されます。お使いのWindowsログインユーザーのみが復号可能です。

4. 人工知能（AI）利用時のデータフロー（BYOK）

Nova AIを利用する際のリクエストは、設定された各モデルプロバイダー（Bring Your Own Key）またはローカルのOllamaインスタンスへ直接送信されます。Lastbrowserの中継サーバーが会話内容を傍受・記録することは技術的に不可能です。

5. GDPR等のデータ権利と主権

外部サーバーに個人データを一切蓄積しないため、データの閲覧・エクスポート・削除の完全な権利が常にユーザー自身にあります。該当ローカルフォルダーを削除するだけで、痕跡なく完全に消去できます。
