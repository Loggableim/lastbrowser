## Design and interaction notes

- Left side reuses the in-tree Sidekick avatar and shows the conversation title plus short Space context.
- Right side keeps New chat and Settings visible; compression and Developer API tools remain available in the overflow with their existing handlers.
- Status comes from the actual service readiness snapshot. A missing snapshot displays neutral “Status unknown”; ready is only shown after the existing API health gate.
- Accent styling uses the existing `--lb-accent` theme token. Narrow layouts, focus outlines, Escape close, outside-click close, and reduced-motion handling are included.
- Connection details were not added because no existing chat-header action handler is present for that item.
