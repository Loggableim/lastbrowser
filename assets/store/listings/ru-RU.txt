LastBrowser — ru-RU

DESCRIPTION
LastBrowser объединяет браузер на базе Chromium для Windows и встроенного ИИ-помощника Nova. Организуйте веб-страницы с помощью вертикальных вкладок и рабочих пространств и используйте помощника рядом с открытыми страницами.

Возможности:
• Вертикальные вкладки и рабочие пространства для ваших веб-проектов.
• ИИ-помощник Nova для вопросов, кратких изложений и работы с предоставленным вами контекстом веб-страниц.
• Подключайтесь со своими учетными данными к проверенным и квалифицированным сочетаниям поставщика и модели ИИ; локальные модели Ollama могут быть доступны. Непроверенные бета-сочетания скрыты по умолчанию и, если предлагаются, требуют явного включения в настройках.
• Встроенный терминал и поддержка расширений браузера.
• Локальное хранение профилей браузера и инструменты для удаления данных просмотра.
• В чатах по умолчанию используется одна модель. Оркестрация Teamwork — бета-функция, включаемая пользователем.

LastBrowser можно бесплатно использовать в личных и коммерческих целях. Внешние ИИ-сервисы могут требовать учётную запись и оплату. При использовании внешнего поставщика ИИ ему отправляются ваш запрос и предоставленный вами контекст задачи. Профили браузера хранятся локально на вашем ПК. Продолжают действовать лицензии и условия сторонних компонентов, моделей и внешних сервисов.
SHORT DESCRIPTION
Браузер Chromium для Windows с вертикальными вкладками, рабочими пространствами и ИИ-помощником Nova. Профили хранятся локально; внешние ИИ-сервисы получают предоставленные вами запросы и материалы.
