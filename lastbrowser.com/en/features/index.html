New in version 0.1.45

Version 0.1.45 was released on October 5, 2026. These notes distinguish checked UI and loopback paths from open local-model quality, RAM-guard, and clean-Windows qualification.

v0.1.52 · UI checked

Compact chat composer

AUTO and “More” keep the default view short; detailed provider and selection policy lives under Advanced. AUTO prefers an eligible configured orchestrator. Otherwise it uses fresh observed limit headroom only when known for every candidate, then compares active and recent local requests, with configured order breaking ties. It does not optimize semantic quality; router qualification remains open.

v0.1.52 · source path checked

Space Assistant & Quick Chat

The Assistant stays bound to its Space and browser profile and streams chat and task status. Short page actions such as summarize and explain use a separate transient Quick Chat instead of a regular chat.

v0.1.52 · loopback checked

Compact persistent goals

Goals can be controlled from chat and retain status and Space binding across shell reloads. The current probe used a controlled local provider; it does not establish external-provider or packaged release readiness.

Local inference: not qualified

Simple Local AI setup

The short flow checks the PC and guides recommendations and setup. Downloading a model does not make inference ready: the 350M router failed its independent holdout, the RAM guard is not qualified across supported hardware, and runtime, license/redistribution, and package checks remain open.

Limited

AUTO & Teamwork

AUTO prefers an eligible configured orchestrator. Otherwise it uses fresh observed limit headroom only when known for every candidate, then compares active/recent local requests and uses configured order to break ties. It does not optimize semantic quality or cost. The local 350M router failed its independent holdout. Teamwork remains a separate explicit feature.

Controlled actions

Browser and tool actions follow the selected profile and visible approvals. A provider that processes data is not presented as local or offline execution.

The 5 Pillars of Lastbrowser

💻

1. ConPTY Windows Terminal

No need to leave the browser for commands. Press Ctrl+\` to reveal a native Windows terminal right inside the sidebar. Run PowerShell, CMD, Git, npm, or Docker seamlessly.

2. Spaces & Session Isolation

End cookie bleed forever. Every Space runs in a dedicated partition: persist:profile:<spaceId>. Log into Space A with personal Google and Space B with enterprise credentials in the same window.

🤖

3. Nova AI & Sidekick Engine

Nova brings chat and curated skills together. Configure available AI providers in settings or use local Ollama models. Model availability and any charges depend on the provider.
