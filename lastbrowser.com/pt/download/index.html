Perguntas Frequentes sobre o Download

Esclarecimentos diretos para as dúvidas técnicas mais comuns durante a instalação.

Como desinstalar o Lastbrowser completamente?

Abra Configurações do Windows > Aplicativos instalados e desinstale o Lastbrowser. O Windows pode remover os dados armazenados no pacote durante a desinstalação. Consulte a política de privacidade para conhecer os locais dos perfis.

Existem versões para macOS ou Linux?

Pacotes Linux x64 assinados. Execute AppImage ou extraia o arquivo tar.gz. A versão macOS continua em preparação.
