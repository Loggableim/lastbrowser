# Issue #284: Änderungen nach einem Update

Stand: 26. November 2026. Der aktuelle Arbeitsstand bestimmt anhand gespeicherter Versions- und Updateinformationen, ob ein Hinweis angezeigt werden soll, und bündelt die vorhandenen lokalisierten Release-Texte offline. Für unbekannte Zielversionen wird eine allgemeine Updatebestätigung angezeigt, ohne konkrete Änderungen zu erfinden. Die vorhandenen Einträge reichen nicht für die im Issue geforderte lückenlose Dokumentation jeder Tagesbeta: Im aktuellen Katalog stehen Einträge für 0.1.46, 0.1.47, 0.1.48, 0.1.53, 0.1.57-beta.1 und 0.1.57-beta.3. Die tatsächlichen Änderungen fehlender Releases müssen vor Ergänzung anhand der jeweiligen Veröffentlichung verifiziert werden.

Im Verzeichnis `apps/desktop` bestanden `node ../../node_modules/vitest/vitest.mjs run tests/release-notes.test.ts tests/update-notice-state.test.ts`: 17 Tests in zwei Dateien. Sie prüfen unter anderem Versionsbereiche, frische Installationen und Updatebestätigungen; sie belegen weder die Vollständigkeit der Release-Inhalte noch einen Updatevorgang über den Microsoft Store. Draft-PR #341 besteht bereits. Issue #284 bleibt bis zur Klärung der fehlenden Einträge und einem echten Update-Nachweis offen.
