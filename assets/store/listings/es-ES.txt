LastBrowser — es-ES

DESCRIPTION
LastBrowser combina un navegador Chromium para Windows con el asistente de IA integrado Nova. Organiza las páginas web en pestañas verticales y espacios de trabajo y utiliza el asistente junto a las páginas abiertas.

Funciones:
• Pestañas verticales y espacios de trabajo para tus proyectos web.
• Asistente de IA Nova para preguntas, resúmenes y tareas con el contexto de las páginas web que proporcionas.
• Conéctate con tus propias credenciales a combinaciones de proveedor y modelo de IA probadas y cualificadas; puede haber modelos locales de Ollama. Las combinaciones beta no probadas están ocultas de forma predeterminada y, si se ofrecen, requieren activarlas expresamente en Configuración.
• Terminal integrado y compatibilidad con extensiones del navegador.
• Perfiles del navegador almacenados localmente y herramientas para borrar los datos de navegación.
• Los chats usan un único modelo de forma predeterminada. La orquestación Teamwork es una versión beta opcional.

LastBrowser es gratuito para uso personal y comercial. Los servicios externos de IA pueden requerir una cuenta y servicios de pago. Cuando utilizas un proveedor externo de IA, tu solicitud y el contexto que proporcionas para la tarea se envían a dicho proveedor. Los perfiles del navegador se guardan localmente en tu PC. Siguen aplicándose las licencias y condiciones de los componentes de terceros, modelos y servicios externos.
