# Windows protected Spaces runtime inventory

**Scope:** The Windows x64 payload staged by [`prepare-windows-space-runtime.mjs`](../../apps/desktop/scripts/prepare-windows-space-runtime.mjs) at the post-[PR #384](https://github.com/Loggableim/lastbrowser/pull/384) source baseline. Inspection on 17 November 2026 covered the pinned input archives and the staged payload. This is a technical inventory without redistribution approval.

The three input archives matched the build script's SHA-256 pins. Windows packaging takes the full staged directory into `resources/protected-spaces`. The script embeds the app's Java initializer and compiles its Windows key helper against TSS.Net. WinFsp runs as a separately installed system driver.

Its `runtime/legal` directory includes GPLv2 and Classpath terms and module notices. The matching Azul source and patches still need to be included in the release's source-delivery review. [Azul release notes for 24.28.87](https://docs.azul.com/core/pdfs/24-ga/azul-zulu-ca-release-notes-24-ga-rev1.0.pdf)

The staged payload includes no WinFsp driver or installer. The native helper probes for an installed WinFsp driver, and the app invokes the Cryptomator FUSE adapter when mounting a vault. The [WinFsp project](https://github.com/winfsp/winfsp) provides GPLv3 with a FLOSS exception and a separate commercial option. Verify the applicable linking terms for the actual distribution, especially before including WinFsp or using it with non-FLOSS components.

## Before distribution

- The packaged [vault initializer](../../apps/desktop/scripts/InitializeSpaceVault.java) imports and calls CryptoFS, CryptoLib and the FUSE adapter in the same Java process. Assess the combined work under the actual terms. GPLv3 and AGPLv3 section 13 provide a path for qualifying combinations while retaining the respective licenses. Identify the combination's full corresponding source, including LastBrowser integration and build inputs where applicable. A separate commercial agreement is an alternative only if it covers the actual components and distribution. [GNU GPL compatibility guidance](https://www.gnu.org/licenses/license-compatibility.en.html) · [Cryptomator CLI terms](https://github.com/cryptomator/cli/blob/0.6.2/README.md#license)
- Fix the missing notices identified by the component-level review. Verify that the final installer preserves notices and equivalent source access or another applicable source-delivery mechanism for the distributed copyleft code. Validate both Java runtimes and the Cryptomator archive's JARs and native contents using the exact released bits.
- Keep the [existing LastBrowser license-scope limits](../../LICENSE-SCOPE.md). No commercial grant or approval for the Store distribution was inspected.
